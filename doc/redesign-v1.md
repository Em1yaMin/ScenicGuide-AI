# 访客端视觉重设计 · 第一阶段（V1）设计计划

> 船长 2026-08-09 触发。范围：设计体系 token + 首页 + 对话页 + 登录/注册对齐。
> 第二阶段（管理后台重设计）将复用本 token 体系。
> 本文件为权威设计文档：所有颜色/字体/动效决定必须源自本节，后续阶段改 token 需同步本节。

## 1. Ground it in the subject

- **主题**：智慧景区 AI 导览——数字人陪伴游客的山水之旅。
- **受众**：到访景区的游客（可能初次到访，需要 10 秒内建立信任：知道"这里有个数字人导览，值得点开始对话"，并看到景区有什么）。
- **页面唯一职责**：
  - 首页：数字人导览的"门面"——一个论点（AI 数字人为您导览）+ 三样真实内容（公告/热门景点/推荐路线，活数据）。
  - 对话页：沉浸式数字人对话，周边 UI 只做辅助（加载态、推荐问句浮层），不抢主体。
- **设计语言来源（主题世界）**：水墨山水卷轴（宣纸/墨色/山峦剪影）、画作落款（朱砂印章）、题跋（题字小标）、旅途（路线序数/行程时长）。
- **真实内容构建**：首页公告来自 `/api/v1/announcements`、景点/路线来自 `/api/v1/home/highlights`（含 location/duration/recommend_reason 等字段，卡片展示它们而非装饰）。

## 2. Token 系统（权威表）

### 2.1 色彩（5 个命名色 + 3 个派生，全部 hex）

| Token | 命名 | Hex | 角色与用法 | 对比度 |
|---|---|---|---|---|
| `--ink` | 墨 | `#1E2A26` | 主文字/标题（青墨，非纯黑） | 正文 on paper ≈ 13:1 |
| `--paper` | 宣纸 | `#F7F8F6` | 页面底色（冷调近白，**刻意避开暖米色**） | — |
| `--jade` | 青玉 | `#2F6B5B` | 主强调：动作按钮/链接/激活态/路线序数 | 文字 on paper ≈ 5.8:1 |
| `--cinnabar` | 朱砂 | `#C1412F` | 次强调：印章落款/置顶徽标/错误。**全页限量使用** | 白字 on 朱砂 ≈ 6.9:1 |
| `--mist` | 山岚 | `#E4E9E5` | 分隔线/卡片边框（灰绿调） | — |
| 派生 | | | | |
| `--slate` | 黛 | `#5C6B63` | 次级正文（描述/日期/元信息） | on paper ≈ 5.2:1 ✓ |
| `--jade-soft` | 青玉淡 | `#E3EDE8` | 标签浅底/hover 底 | — |
| `--surface` | 素白 | `#FFFFFF` | 卡片/浮层底 | — |

色相逻辑：墨绿青玉为骨（山水），宣纸为底（卷轴），朱砂只作印（落款）。**全页朱砂出现 ≤ 3 处**：hero 印章、置顶徽标、section 题跋点。

### 2.2 字体（3 角色，CDN 已带系统兑底）

| 角色 | 字体栈 | 用途 |
|---|---|---|
| 题字 | `Noto Serif SC` 700 / 兑底 `STSong, serif` | 标题、路线序数「一二三」、品牌 |
| 正文 | `Noto Sans SC` 400/500 / 兑底 `PingFang SC, Microsoft YaHei` | 正文/按钮/标签 |
| 数据 | `JetBrains Mono` / 兑底 `monospace` | 日期、时长、行程元信息 |

刻意搭配点：标题全用 700 宋体 + 收紧字距（`letter-spacing: 0.02em`）；数据一律 mono——"日期是数据，不是装饰"。

### 2.3 字阶

`--text-hero: clamp(2.5rem, 6vw, 4.25rem)` · `--text-display: clamp(1.75rem, 3.5vw, 2.5rem)`（比旧值收敛，section 标题不喧宾）· `--text-title: 1.5rem` · `--text-subtitle: 1.125rem` · `--text-body: 1rem` · `--text-small: 0.875rem` · `--text-caption: 0.75rem` · `--text-tiny: 0.6875rem`（印章/角标）。

### 2.4 间距 / 圆角 / 阴影 / 动效

- 间距沿用既有 `--space-*`（xs .5 / sm .75 / md 1 / lg 1.5 / xl 2.5 / 2xl 4 / 3xl 6 rem）+ 新增 `--space-section: clamp(3.5rem, 8vw, 6rem)`（区块纵向节奏）。
- 圆角：`--radius-sm: 6px` · `--radius-md: 10px` · `--radius-lg: 16px` · `--radius-full: 999px`（收敛旧的 4/6/8/10/12 混用）。
- 阴影：`--shadow-card: 0 1px 2px rgba(30,42,38,.04), 0 4px 12px rgba(30,42,38,.05)` · `--shadow-pop: 0 8px 24px rgba(30,42,38,.10)`（轻柔，无大光晕）。
- 动效：沿用 `--duration-fast/normal/slow` + `--ease-out`；新增 `--ease-stamp: cubic-bezier(0.34, 1.56, 0.64, 1)`（印章落定的轻微回弹）。`prefers-reduced-motion` 全局降级。

## 4. 签名元素（本页最独特的记忆点）

**朱砂印章落款「AI 导览」**——48px 方印（朱砂底白字，两行：AI / 导览，轻微 -2° 旋转），压在 hero 右下山峦剪影上；入场序列最后以 `--ease-stamp` 盖章落定（放大→回位+轻旋）。

- 印章母题全站回响（设计语言自洽）：置顶公告 = 朱砂「置顶」迷你印；section 标题 = 8px 朱砂方点（题跋点）；footer = 微缩印章文字。
- 为什么是它：印章是"落款/署名/可信"的文化符号——恰好是数字人导览想传达的"这是精心准备的导览"；且极少出现在 Web 模板中，反模板感强。
- 山峦剪影为支持元素（水墨分层 SVG，aria-hidden，移动端收缩为底部细条）。

## 5. 动效编排（只选一处）

- **唯一编排**：Hero 入场序列（小标 → 题字 → 副文 → 动作 → 印章落款，stagger 80ms，`--ease-out`）。
- 其余全部安静：无滚动显现、无卡片悬浮位移（hover 只换边框/底色这类功能反馈）、浮层开合仅 200ms 淡入上滑。
- `prefers-reduced-motion`：关动画、关印章回弹。

## 6. 自审（对照 brief，双遍流程第二遍）

### 6.1 规避三种 AI 默认风格

| 默认风格 | 本项目现状/对策 |
|---|---|
| ① 暖米色 + 高对比衬线 + 赤陶强调 | **旧版正是此风格**（#F7F5F0 + Noto Serif + #C45C26）。对策：底色改冷调宣纸 #F7F8F6、强调改青玉 #2F6B5B、赤陶降级为限量朱砂印 |
| ② 近黑底 + 荧光绿/朱红强调 | 未采用（保留浅色底，服务"景区导览"的轻松可信） |
| ③ 报纸发丝线 + 零圆角 + 密排 | 未采用（保留克制圆角与 1.5rem 级呼吸间距） |

### 6.2 "换任何项目都这么写"的通用件 → 已替换

1. ❌ 路线序号 `01/02/03`（通用 editorial 列表）→ ✅ 卷轴式中文数字「一/二/三」题字。
2. ❌ 毛玻璃公告卡 + 渐变光晕（通用 SaaS 通知条）→ ✅ 题签卡（青玉侧签 + 置顶朱砂迷你印）。
3. ❌ Hero 渐变光晕/噪点背景（通用模板）→ ✅ 水墨山峦剪影 + 印章落款。
4. ❌ 16:9 emoji 占位大图卡（通用图片位）→ ✅ 等宽"意象"卡：青玉淡底 + 大 emoji 意象 + 真实数据行（location · 时长）。
5. ❌ 花哨入场动画 → ✅ 只留 Hero 一处分段编排 + 印章落款。

### 6.3 克制清单（收尾再自审）

- 印章是唯一"大胆"：全页只此一处视觉钩子；其余装饰（噪点、渐变、玻璃拟态、滚动显现）一律不引入。
- 卡片 hover 只换边框/底色（功能反馈），不做位移/浮起。
- 朱砂全页 ≤ 3 处。
- 文案全部保留现有中文内容（E2E 守护：hero 题字含「AI 数字人」、「开始对话」「浏览推荐」按钮、公告/卡片/路线文案）。

## 7. 可访问性

- 语义化：header/nav/main/section/article/footer/button/time 保持并强化；浮层加 `role="region"` + `aria-label`，收起按钮 `aria-expanded`。
- 对比度：正文 ≥4.5:1（见 2.1 表，全部达标）。
- 键盘：全局 `:focus-visible` 青玉 2px 外描边（`--color-focus` token）。
- `prefers-reduced-motion` 媒体查询降级。

## 8. 兼容策略（供阶段 2 复用）

- 新建 `src/styles/design-tokens.css` = 唯一权威 token 源（新命名：`--ink/--paper/--jade/--cinnabar/--mist/--slate/--surface/--radius-*/--shadow-*/--space-section/--ease-stamp`）。

- 页面级组件迁移到新 token 名。
